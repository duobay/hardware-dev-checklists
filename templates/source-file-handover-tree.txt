SAMPLE: SOURCE-FILE HANDOVER PACKAGE (directory tree)
=====================================================
Duobay, a service of Aximora Labs Inc.
Hypothetical project: "T1", an LTE-M / GNSS asset tracker for a US client.
This is an illustrative example of the structure we deliver. It is not a real
client project. File names, revisions and tools are examples only.

How to read it
--------------
- One top-level folder per gate. Each gate folder is delivered when that gate
  is paid, and the files in it are assigned to you at that point.
- Later gates contain the full, current design. Earlier gate folders stay in the
  package so you keep the history.
- Firmware lives in a Git repository in YOUR organization (GitHub, GitLab or
  Bitbucket). The "firmware/" entries below show what that repository contains
  at the tagged release for the gate.
- Every native source file is included, not only exports. Exports (PDF, Gerber,
  STEP) are there so anyone can review without the CAD tool.
- MANIFEST.sha256 lists a SHA-256 hash for every file so you can verify the
  package arrived complete.

What is NOT in the package
--------------------------
- Third-party software and tools under their own licenses (chip vendor SDKs,
  modem firmware, CAD tools). They are listed in the SBOM with name, version and
  license. We cannot assign what we do not own.
- Our own pre-existing reference designs and libraries, if any were reused.
  Those are licensed to you for your product as set out in the MSA; the files
  you need to build, modify and manufacture the product are still included.
