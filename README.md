# Hardware development checklists

Free checklists and templates for teams building a connected device with an outside engineering vendor:
what to collect at each development gate, how to handle FCC when you use a pre-certified radio module, and
which source files you should hold before you pay for the next stage.

They are vendor-neutral. Use them with any design house, including us.

| File | Use it when | Background reading |
|---|---|---|
| [checklists/gate-exit-checklist.md](checklists/gate-exit-checklist.md) | Closing a gate (concept, EVT, DVT, PVT, small batch): evidence, files in hand, go / adjust / stop | [EVT, DVT, PVT: what you should get at each stage](https://duobay.ai/insights/evt-dvt-pvt-what-you-get?utm_source=github&utm_medium=referral&utm_campaign=checklists) |
| [checklists/fcc-modular-checklist.md](checklists/fcc-modular-checklist.md) | Your device uses a radio module that already has its own FCC ID | [Pre-certified LTE modules and FCC](https://duobay.ai/insights/pre-certified-lte-module-fcc?utm_source=github&utm_medium=referral&utm_campaign=checklists) |
| [templates/sbom-sample.csv](templates/sbom-sample.csv) | Asking a vendor for a software bill of materials with the firmware | [SBOM and source-file handover checklist](https://duobay.ai/insights/sbom-source-file-handover-checklist?utm_source=github&utm_medium=referral&utm_campaign=checklists) |
| [templates/source-file-handover-tree.txt](templates/source-file-handover-tree.txt) | Agreeing up front what a complete handover folder looks like | [Who owns the source files under a US contract](https://duobay.ai/insights/who-owns-source-files-us-contract?utm_source=github&utm_medium=referral&utm_campaign=checklists) |

Each file carries its version and the date its rules were checked. Regulations change: confirm anything
regulatory with your test lab before you rely on it. These are checklists, not legal advice.

## Suggest a change

Open an issue or a pull request if a line is wrong, out of date, or missing something you needed on a real project.
